# DC Series

The **DC Series** is a collection of beginner-friendly Linux boot2root machines created by **DCAU (Darren Martyn)** and hosted on **VulnHub**.

These machines focus on developing a structured penetration testing methodology, including reconnaissance, enumeration, exploitation, privilege escalation, and post-exploitation. Each write-up documents my approach, the techniques used, and key lessons learned throughout the engagement.
